# HeatSense Hub

HEATKSHETRA — HEATWAVE GIS MONITORING & HUMAN HEAT-RISK DASHBOARD

Create the FRONT PAGE / HOMEPAGE of a modern premium web application called “Heatkshetra” for Smart India Hackathon 2026 – Problem Statement 83.

The application is a GIS-based Heatwave Monitoring and Human Heat-Risk Dashboard.

CORE CONCEPT

“Don’t just show the weather. Show what the heat means for people.”

The design should look like a professional GIS monitoring dashboard, NOT like a normal weather app.

Use the attached reference image as the primary visual/layout reference. Recreate the same overall composition, density, proportions, dark dashboard aesthetic, map placement, cards, and visual hierarchy, while adapting the content to Heatkshetra.

---

1. OVERALL PAGE STRUCTURE

Create a desktop-first dashboard homepage with a fixed/sticky top navigation bar.

Below the navbar, divide the main dashboard into two large horizontal panels:

LEFT — approximately 39–40% width

Personal heat-risk information.

RIGHT — approximately 60–61% width

Large GIS heat-risk map.

The GIS map must be the dominant visual element.

The page should immediately communicate:

LOCATION → TEMPERATURE → HEAT INDEX → RISK → ACTION → GIS MAP

Do NOT create a traditional centered landing page with a large hero heading.

This should look like a real operational monitoring dashboard.
